# Design guide

Load this when the user asks how the deck should look, or when the deck will be built into slides rather than pasted as text.

The skill does not render slides. This file tells the presenter, or whoever builds the deck, what to do with the structure.

## The one rule

One message per slide.

If a slide carries two messages, it is two slides.

## Layout

| Element | Guidance |
|---------|----------|
| Headline | One line, a claim. Top third of the slide. |
| Body | 3-5 bullets, max 12 words each. Left-aligned. |
| Evidence | One chart, diagram or image. Never two competing visuals. |
| Footer | Source, date, page number. Small and quiet. |

Keep a consistent outer margin on all four sides. Nothing touches the slide edge.

## Type scale

| Level | Minimum size | Use |
|-------|--------------|-----|
| Title | 36pt | Slide headline |
| Body | 24pt | Bullets and labels |
| Caption | 16pt | Sources and footnotes |

If text does not fit at these sizes, cut text. Do not shrink type.

## Colour

- One background colour, one text colour, one accent colour.
- The accent colour marks the single most important number or action per slide.
- Never colour text for decoration.
- Dark text on a light background. Avoid dark gradients behind body text.

## Charts

| Data story | Chart |
|------------|-------|
| Change over time | Line |
| Comparison across items | Bar |
| Composition of a whole | Stacked bar or treemap |
| Relationship between two values | Scatter |
| One headline number | Big number, no chart |

Rules:

- Title the chart with the conclusion, not the axis labels.
- Remove gridlines that carry no information.
- Label the data point you want remembered.

## Tables

Tables beat paragraphs. Charts beat tables.

A table with more than four columns belongs in an appendix.

## Common failures

| Failure | Why it fails | Fix |
|---------|--------------|-----|
| Bullet dump | No message, only content | Write the headline claim first, keep only bullets that support it |
| Wall of text | The audience reads instead of listening | Cut to five bullets, move detail to the notes |
| Decorative imagery | Consumes attention, carries nothing | Replace with evidence or delete |
| Inconsistent margins | Reads as careless | Set margins once, apply everywhere |
| Many fonts | Visual noise | One family, two weights |
| Chart with no conclusion | The audience does the analysis | Retitle with the takeaway |

## Handoff

When the user builds the deck themselves, hand over:

1. The slide list with headlines
2. Bullets per slide
3. The visual suggestion per slide
4. Speaker notes
5. A note on type scale and colour count

That is enough to build the deck without further decisions.
